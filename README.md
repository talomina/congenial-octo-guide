# アルボバス時刻表

アルボの丘と稲城駅・南多摩駅を結ぶバスの時刻表ページです。
2024年4月1日改正の時刻表をもとにしています。

## 特徴

- **駅別タブ**：「南多摩駅 発着」「稲城駅 発着」を切り替え、各駅の往路・復路をまとめて表示
- **次のバス表示**：現在時刻から次の発車時刻と「あと◯分」を自動表示（20秒ごとに更新）。本日の運行終了後は翌日の始発を表示
- **ハイライト**：次のバスの時刻と現在時刻の時間帯を強調表示し、発車済みの便は薄く表示
- ダークモード対応（端末の設定に連動）
- HTMLファイル1つだけで動作（ビルド不要、外部ライブラリなし）

## 使い方

`index.html` をブラウザで開くだけで動作します。

## 時刻表データの更新

時刻表は `index.html` 内の `STATIONS` オブジェクトに埋め込まれています。
ダイヤ改正時は、各駅・各方向の `[時, [分の配列]]` を書き換えてください。

## 注意

- 時刻は発車時刻です。道路事情により遅れる場合があります。
- 運行のない時間帯は掲載していません。
